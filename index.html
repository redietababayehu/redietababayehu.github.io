Projects

  • GardenPro

    May 2026 to present

    An audio-first app for smart glasses that helps blind and low-vision children identify plants and hear how to care for them.

    • CARA. I created the Confidence-Aware Adaptive Response Architecture, which maps identification confidence to different spoken responses so the app never presents an uncertain guess as fact.
    • Growth tracking. Children track plants over time by voice, and Soundex phonetic matching handles speech-to-text errors in plant names.
    • Seed pre-detection using Claude vision, alongside PlantNet for plant identification and ElevenLabs for speech.
    • Usability study. I ran a 5-task study with 13 participants, preparing consent forms, facilitator scripts, and age-matched questionnaires. Command recognition and renaming were the main pain points.
    • Community-informed. Shaped by early outreach to Blind Beginnings.
    • MentraOS SDK
    • Bun
    • PlantNet API
    • Claude API
    • ElevenLabs TTS

  • Stance analysis of YouTube comments

    May to August 2025

    A study of online discourse after severe extremist attacks, using large YouTube comment and reply datasets.

    • Built data pipelines to clean, filter, and label millions of text records, including language detection, sentiment scoring, and feature engineering.
    • Used LLMs for sentiment, emotion, and stance analysis, then measured how emotionally opposing comments affect engagement and discussion.
    • Combined NLP, network analysis, and statistics in a paper published at IEEE UEMCON 2025.
    • Python
    • LLMs
    • NLP
    • Network analysis
